# Nipona's Family Daycare Website

A modern single-page website for Nipona's Family Daycare.

## Features
- Responsive marketing website
- Contact/tour inquiry form with direct:
  - WhatsApp pre-filled message
  - Email pre-filled message
- Interactive schedule and fee gap estimator
- Google Maps location section

## Publish Live (GitHub Pages)
1. Create a new GitHub repository.
2. Upload this project (including the `.github/workflows/deploy-pages.yml` file).
3. Push to the `main` branch.
4. In GitHub, open **Settings → Pages** and set **Source** to **GitHub Actions**.
5. Wait for the workflow to finish. Your site will be live at:
   - `https://<your-username>.github.io/<your-repository-name>/`

## Optional: Publish with Netlify
1. Sign in to Netlify.
2. Click **Add new site → Import an existing project**.
3. Select your GitHub repository.
4. Build settings:
   - Build command: *(leave empty)*
   - Publish directory: `.`
5. Deploy.
